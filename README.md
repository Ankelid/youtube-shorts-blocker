# YouTube Shorts Blocker

Легковесное расширение для браузеров на базе Chromium, которое:
1. **Скрывает все элементы Shorts**: боковые кнопки, блоки в ленте подписок, рекомендации на главной, полки в поиске, вкладку Shorts на страницах каналов и кнопку-фильтр над выдачей.
2. **Перенаправляет при прямом переходе**: автоматически перенаправляет на главную страницу (или в стандартный плеер).
3. **Удобный тумблер Вкл/Выкл**: при клике на значок расширения на панели браузера можно мгновенно включить или отключить блокировку без перезагрузки страницы.
4. **Высокая производительность**: оптимизирован для моментального поиска без задержек и подвисаний.

---

## 🌐 В каких браузерах работает?

Расширение работает во **всех браузерах на базе Chromium**:
- **Google Chrome**
- **Яндекс Браузер**
- **Microsoft Edge**
- **Opera / Opera GX**
- **Brave**
- **Vivaldi**

Установка везде одинаковая.

---

## 🚀 Установка и обновление

1. Откройте в браузере страницу расширений:
   - В **Google Chrome**: `chrome://extensions/`
   - В **Яндекс Браузере**: `browser://extensions/`
   - В **Microsoft Edge**: `edge://extensions/`
2. Включите тумблер **«Режим разработчика»** (*Developer mode*).
3. Если расширение уже установлено — нажмите значок **«Обновить»** (🔄) на карточке **YouTube Shorts Blocker**.
   Если устанавливаете впервые — нажмите **«Загрузить распакованное расширение»** и выберите папку:
   `D:\Papka\gamevib\klick_site\youtube-shorts-blocker`
4. Закрепите расширение на панели браузера (нажмите на значок «пазла» 🧩 рядом с адресной строкой и кликните на «булавку» напротив Shorts Blocker).
5. Теперь при клике на значок расширения откроется всплывающее меню с тумблером **Вкл / Выкл**.
